# 🍕 Pizza Express

Aplicativo mobile desenvolvido em **Android Studio** como projeto acadêmico, com o objetivo de simular um pedido de pizzas de forma simples e interativa.

## 📌 Sobre o projeto

O **Pizza Express** é uma aplicação Android desenvolvida durante a graduação em **Análise e Desenvolvimento de Sistemas (ADS)**.

A aplicação permite que o usuário escolha entre **pizzas salgadas ou doces**, visualize os sabores disponíveis e informe a quantidade desejada de cada pizza.

Após realizar as escolhas, o aplicativo calcula o **valor total do pedido**, permitindo visualizar o resultado da compra.

O projeto foi desenvolvido com foco na prática de criação de interfaces Android, navegação entre telas, interação com o usuário e implementação de cálculos utilizando **Java e XML**.

## 🎯 Objetivo

O principal objetivo do projeto é desenvolver uma aplicação Android simples e interativa para simular um pedido de pizzas.

Além disso, o projeto busca colocar em prática conhecimentos de:

## 🛒 Funcionamento do pedido

O funcionamento do aplicativo é dividido em etapas.

Primeiro, o usuário escolhe entre **pizzas salgadas ou doces**.

Depois, são apresentados os sabores disponíveis de acordo com a categoria escolhida.

O usuário pode selecionar **a quantidade desejada de cada sabor**, podendo montar o pedido de acordo com suas preferências.

Ao finalizar as escolhas, o aplicativo realiza o **cálculo do valor total do pedido** e apresenta o resultado para o usuário.
